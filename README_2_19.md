# Infra Registry 2.19

- Упрощен выбор оборудования в форме физического устройства: единый каталог Производитель → Тип → Модель.
- Добавлено отображение версии ОС физического устройства.
- В подключениях доступны только свободные интерфейсы; backend дополнительно проверяет занятость порта.
- Excel восстановлен к исходному шаблону из ТЗ.
- Количество физических портов в Excel считается по типам интерфейсов.
- Для подключения без IP выводится «не назначен».
- IP соседнего интерфейса выводится из связанных IP интерфейса.
