# Infra Registry 2.13

## Исправления

- В списке физических устройств снова отображаются имя/имена интерфейсов управления и все IP управляющих интерфейсов.
- В списке интерфейсов отображаются IP-адреса интерфейса.
- Добавление и редактирование интерфейса из Dashboard «Интерфейсы» использует тот же редактор, что и порты физического устройства: тип, MAC, скорость, управление, описание и несколько IP-адресов.
- Для подключения backend теперь возвращает понятную ошибку 422, если не выбраны исходный/конечный интерфейсы, вместо SQLite NOT NULL constraint.
- Выбор портов подключения фильтруется по выбранному физическому устройству.

Схема БД не менялась, новая Alembic-миграция не требуется.
