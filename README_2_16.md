# Infra Registry 2.16

Основные изменения:
- единый справочник «Протокол / порт» для протоколов ИС и открытых портов;
- в ИС добавлен единый блок источников размещения/IP: ручной ввод, физическое устройство, ВМ, контейнер;
- IP автоматически подставляются при выборе физического устройства, ВМ или контейнера;
- список ВМ фильтруется по выбранному физическому серверу;
- добавление подразделения через «+ Новое» непосредственно в форме ИС;
- добавление организации технической поддержки сразу появляется в текущем поле без перезагрузки;
- в форме ВМ не используются поля «Гипервизор» и «Состояние устройства».

Миграция Alembic: `8c5d1f7a2b40_is_protocol_catalog_and_sources.py`.
Существующую `infra_registry.db` удалять не нужно.
