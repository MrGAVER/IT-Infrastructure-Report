# Infra Registry 2.24.0

## 1. Виртуальные машины

**«IP администрирования» — не было видно галочки, наезжала кнопка «Удалить».**
Причина в CSS: строка IP-адреса ВМ переиспользовала `.vlan-device-row` (auto-fit сетка), а метка
«IP администрирования» с `white-space:nowrap` не помещалась в свою колонку и визуально наезжала
на соседнюю ячейку с кнопкой «Удалить». Строка получила отдельный класс `.vm-ip-row` с явной сеткой
колонок — переключатель теперь всегда виден и не перекрывается.

**Добавлен блок «Открытые порты / протоколы» для ВМ** — раньше заполнить его было просто нечем:
данные использовались в отчете (Лист 4, «Организация управления ВМ»), но интерфейса для их ввода
не было. Теперь у формы ВМ есть отдельный блок с портом/протоколом/транспортом/описанием и
опциональным выбором из справочника протоколов.

## 2. Информационные системы

**«+ Источник / IP» стирал только что выбранный «- протокол / порт -».**
Причина найдена: все четыре кнопки добавления строк (`+ Подразделение`, `+ Протокол`,
`+ Источник / IP`, `+ Оборудование/ПО/интерфейс`) перерисовывали весь блок «Размещение...» без
предварительной синхронизации текущих значений полей — только что выбранное в любом из соседних
селектов терялось при перерисовке. Исправлено во всех четырёх местах.

**Поле «IP адрес» используется только в режиме «Вручную».** Убрано автозаполнение IP из выбранного
физического сервера/ВМ (и на бэкенде, и во фронтенде) — теперь для этих режимов IP берется из
данных самого оборудования/ВМ при формировании отчета, а не дублируется в поле источника. Поле
визуально блокируется, если режим не «Вручную».

## 3. Подключения

**Поле «Назначение» убрано из формы.** Столбец в БД не тронут (на случай уже введенных данных),
но в интерфейсе редактирования подключения его больше нет — вместо него теперь используются флаги
портов «Управление»/«Передача данных» (см. ниже, отчет Excel).

## 4. Физические устройства

**В блоке «Порты / интерфейсы» добавлена галочка «Передача данных»** рядом с «Управление» — и в
карточке интерфейса, и в панели массового редактирования. Новое поле `is_data_transfer` в
`device_interfaces` (миграция `f6b3d8e2a941`).

## 5. Отчет Excel — лист «Организация подключений»

**Строки больше не чередуются между устройствами.** Раньше при нескольких подключениях с
произвольным порядком src/dst строки для двух устройств могли идти вперемешку (как в примере из
задачи). Теперь после построения всех строк они группируются по «своему» устройству — все строки
одного устройства идут подряд.

**«Сведения о назначении линий связи» теперь строится из флагов порта**, а не из удаленного поля
«Назначение» подключения:
- только «Управление» → «Управление активами»
- только «Передача данных» → «Передача данных»
- оба флага → «Управление активами, передача данных»
- ни одного → «-»

**Пустые ячейки листа заполняются «-»** вместо пустой строки.
