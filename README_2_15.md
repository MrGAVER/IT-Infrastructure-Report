# Infra Registry 2.15

Изменения:
- Подключения: в списке отображаются исходное/конечное физическое устройство и порт.
- ИС: добавлен отдельный справочник организаций технической поддержки с быстрым добавлением через `+`.
- ИС: подразделения можно добавлять через `+`; добавлен выбор родительского подразделения.
- ИС: протокол содержит `Протокол/технология`, `Порт`, `Описание`; поля `Версия` и `Направление` больше не используются в форме.
- ИС: IP можно связать с физическим сервером или виртуальной машиной. При выборе сервера список ВМ автоматически ограничивается ВМ этого сервера. IP заполняются из интерфейсов сервера или IP ВМ.
- Миграция БД `6f4b2c8d1a90` добавляет каталог организаций поддержки, порт протокола и связи IP ИС с физическим устройством/ВМ.
- Версия приложения: 2.16.0.

Существующую `infra_registry.db` удалять не нужно. При запуске EXE Alembic применяет миграцию автоматически.
