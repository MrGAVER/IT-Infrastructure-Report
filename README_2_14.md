# Infra Registry 2.14.0

Исправления:
- Подключения: выбор исходного/конечного устройства и интерфейса с явной валидацией.
- Интерфейсы: единый редактор с IP-адресами, в том числе несколько IP на интерфейс.
- Информационные системы: отдельный редактор связанных подразделений, IP, протоколов, физических устройств, VM и контейнеров; поля `Тип` и `Состояние устройства` исключены из формы.
- Виртуальные машины: убраны поля `Гипервизор` и `Состояние устройства`; гипервизор автоматически определяется по ОС выбранного физического хоста.
- Для хоста VM доступны только физические устройства типа `Сервер` или `Система хранения данных` (также распознается `Storage`).
- Существующая БД не требует новой миграции.
