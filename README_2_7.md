# Infra Registry 2.8

## Основные изменения

1. ОС физического устройства показывается в формате «Наименование версия».
2. UUID внешних ключей в таблицах заменены на читаемые названия (ИС, устройства, ОС, модели, интерфейсы и т.п.).
3. «Порт управления» теперь является свойством интерфейса. В форме физического устройства интерфейсы редактируются в том же окне.
4. Интерфейсы можно сгенерировать по количеству физических портов. Доступны шаблоны имени и номера: `{n}` — номер с 1, `{n0}` — номер с ведущим нулем.
5. Сгенерированные строки можно полностью редактировать, удалять и добавлять вручную.
6. Для интерфейса появился признак «Управление».
7. В Excel лист 2 порт управления определяется по интерфейсу с признаком «Управление»; для старых данных сохраняется fallback на прежнее поле.
8. Добавлена миграция `9e31b7c4a820`.
