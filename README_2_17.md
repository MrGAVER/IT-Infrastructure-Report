# Infra Registry 2.17

## Изменения

1. Исправлено быстрое добавление организации технической поддержки: заголовок окна теперь корректно показывает «Добавить: Организация технической поддержки», а созданная запись сразу появляется в текущем списке без перезагрузки.
2. Dashboard «Информационные системы» теперь отображает IP-адреса, протоколы/порты, физические устройства, ВМ, контейнеры, подразделения и организацию поддержки в читаемом виде.
3. Каталог оборудования переработан как единый иерархический выбор «Производитель → Тип устройства → Модель». В форме физического устройства модель можно выбрать первой: производитель и тип подставляются автоматически. Добавление модели через «+» сразу обновляет каталог и связанные поля.
4. В sidebar добавлен отдельный пункт «Справочники / каталог оборудования».
5. Отчёт Excel переработан: данные листов 1–4 собираются из текущей нормализованной модели, включая IP интерфейсов, management IP, протоколы и описания, размещение ИС, ВМ/контейнеры, программные активы, подключения и открытые порты. Убраны N+1-запросы из отчёта.
6. Форма виртуальной машины сохраняет только физический хост; поля «Гипервизор» и «Состояние устройства» не показываются пользователю. Гипервизор определяется из ОС физического хоста.

## База данных

Новая миграция не требуется: изменения этой версии касаются представления, API-сериализации и формирования отчёта. Существующую `infra_registry.db` удалять не нужно.

## EXE

```bat
rmdir /s /q build
rmdir /s /q dist
installer\build_windows.bat
```

База данных хранится рядом с `InfraRegistry.exe`.
