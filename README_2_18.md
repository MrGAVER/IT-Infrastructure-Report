# Infra Registry 2.18

Исправления версии 2.18.0:

- В списке «Информационные системы» заменены технические имена summary-полей на человекочитаемые заголовки.
- В summary ИС добавлен сбор данных из унифицированных источников: IP, физические устройства, ВМ и контейнеры.
- IP виртуальных машин также учитываются в сводке ИС.
- В форме ВМ окончательно скрыты поля «Гипервизор» и «Состояние устройства».
- В Excel восстановлены исходные заголовки всех 4 листов по первоначальному ТЗ.
- Лист 2 снова содержит 14 исходных колонок, без объединения полей здания/помещения.
- Лист 3 содержит исходные 18 колонок; тип подключения используется в колонке физических линий, назначение — из поля назначения подключения.
