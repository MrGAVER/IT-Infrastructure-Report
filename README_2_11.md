# Infra Registry 2.11

Изменения:
- добавлены стандартные значения в справочники типов устройств, ОС/гипервизоров и скоростей интерфейсов;
- стандартные значения добавляются идемпотентно и не удаляют пользовательские записи;
- из основной формы физического устройства скрыты поля «Порт управления», «IP управления» и «Количество интерфейсов»;
- управление, IP-адреса и количество интерфейсов по-прежнему ведутся в редакторе «Порты / интерфейсы»;
- миграция данных: `f2a9c7d1e530_standard_catalog_values`.

Для существующей БД удалять `infra_registry.db` не нужно. При запуске EXE Alembic применит миграцию автоматически.
