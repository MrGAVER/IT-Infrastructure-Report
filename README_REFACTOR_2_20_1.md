# Infra Registry 2.20.1 — удаление стеков и рефакторинг

## Изменения

- Полностью удалена текущая реализация стеков устройств из приложения:
  - удален `DeviceStack` из ORM;
  - удален `stack_id` из физических устройств;
  - удален справочник стеков из UI/API;
  - удален endpoint агрегирования стека;
  - удалена логика объединения устройств в Excel.
- Добавлена миграция `b5e7c2d4a910_remove_device_stacks.py`.
- При миграции существующей БД связи устройств со стеками удаляются, остальные данные устройств сохраняются.
- Исправлен endpoint списка ВМ: он больше не использует обогащение физических устройств.
- Startup переведен с устаревшего `on_event` на lifespan.
- Для разработки Alembic теперь использует ту же БД, что и приложение: `../infra_registry.db`.
- Удалена дублирующая БД `backend/infra_registry.db`; рабочая БД находится в корне проекта и при EXE — рядом с EXE.
- Сохранены тестовые данные и кнопка `Заполнить тестовыми данными`.
- Сохранен каталог оборудования с быстрым добавлением производителя и типа устройства.
